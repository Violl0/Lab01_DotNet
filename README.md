## Выводы

1. C# компилируется в IL-код, который CLR превращает в машинный при запуске.
2. Тип переменной указывается явно, ошибки ловит компилятор.
3. 10 / 3 даёт 3, для дробного результата нужен double.

## Итоговая таблица

| Характеристика C# / .NET | |
|---|---|
| Платформа | .NET (CLR) |
| Компиляция | C# - IL-код - машинный код |
| Запуск | dotnet run |
| Тип переменной | Указывается явно: int x = 5; |
| Вывод в консоль | Console.WriteLine("текст") |
| Ввод от пользователя | Console.ReadLine() |
| Интерполяция строк | $"Привет, {name}!" |
| Целочисленное деление | 10 / 3 = 3 |
| Дробное деление | (double)10 / 3 = 3.333... |
| Математические функции | Math.Abs(), Math.Pow() и др. |

## Ответы на вопросы

1. Write выводит без перевода строки, WriteLine с переводом.
2. Ошибка компиляции, double в int автоматически не преобразуется.
3. Оба числа int дробная часть отбрасывается. Нужно (double)10 / 3.
4. var выводит тип при компиляции, тип потом не меняется. В Python тип можно менять во время выполнения.
5. Unity, Stack Overflow, Microsoft (Azure).
